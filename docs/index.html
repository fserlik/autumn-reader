THE LATEST EDITION

The page now reads with you.

Autumn Reader's newest tools keep narration private, preserve your visual place, and make long-form reading more comfortable without crowding the book.

01 / OFFLINE VOICES

A voice library that belongs to your device.

Choose a system voice or import compatible Piper and Kokoro models. The library lists only voices that are installed and ready to use—there is no online voice shop and no automatic model download.

  • Import sherpa-onnx packages and individual Kokoro voice files.
  • Share one compatible Kokoro base model across several voices.
  • Preview, set a default, inspect storage, or remove imported voices.
Open the voice guide
02 / FOLLOW THE TEXT

Pause the voice. Keep the line.

Read aloud begins at the visible part of an EPUB or adaptable PDF. The current word or passage is marked on the page and remains marked while paused, so resuming never means searching for your place.

  • Play, pause, stop, and move between coherent fragments.
  • Remember speed, pitch, and an optional installed voice per book.
  • Prepare the next local fragment without blocking the reader.
Learn about read aloud
03 / ADAPTABLE PDF

PDF text with the breathing room of an EPUB.

When a PDF contains selectable text, adaptable mode lays it out as a calm editorial page instead of stretching lines across the window. Original-page mode remains available whenever the authored layout matters.

  • Readable measure, columns, margins, type, and book themes.
  • Text size changes without enlarging the paper itself.
  • Notes, search, progress, and read aloud follow the adapted text.
