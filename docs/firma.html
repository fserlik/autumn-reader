Estado actual

El instalador de Windows publicado hasta ahora no tiene firma digital. Autumn Reader está preparando su solicitud de firma gratuita a SignPath Foundation. Hasta que esa solicitud se apruebe y se publique una nueva versión firmada, los instaladores existentes seguirán apareciendo como no firmados.

Una vez aprobado el proyecto: Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Procedencia y publicación

Las versiones firmadas se compilarán desde el repositorio público de Autumn Reader en GitHub Actions. Solo se enviarán a SignPath instaladores producidos por ese flujo a partir de etiquetas de versión que coincidan con el código. Cada solicitud de firma requerirá aprobación manual y la firma se verificará antes de crear la release de GitHub.

Los instaladores disponibles se enlazan desde la página de descargas. No firmamos aplicaciones de terceros con el certificado del proyecto.

Responsables

fserlik mantiene el proyecto y cumple los roles de autor, revisor de contribuciones externas y aprobador de solicitudes de firma. Las cuentas con acceso al repositorio y a SignPath deben usar autenticación de dos factores.

Privacidad

La aplicación puede guardar una copia de tu biblioteca en Google Drive solo cuando lo solicitas. Consulta la política de privacidad para conocer los datos locales, el acceso a Drive y cómo eliminar las copias.
